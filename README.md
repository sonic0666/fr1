# Сервис управления подписками на уведомления

## Назначение
Приложение позволяет пользователям управлять подписками на различные типы
уведомлений (email, push, SMS), настраивать частоту получения уведомлений
и отслеживать статус каждой подписки (активна, приостановлена, истекла).
В дальнейшем сервис будет развернут как веб-приложение с личным кабинетом
пользователя и API для сторонних сервисов, интегрирующих отправку уведомлений.

## Целевая аудитория
- пользователи веб- и мобильных сервисов, желающие гибко настраивать,
  какие уведомления и по каким каналам они получают;
- администраторы сервисов-интеграторов, которым нужно управлять рассылками
  и контролировать статус подписок пользователей.

## Предметная область
Управление подписками пользователей на уведомления: регистрация подписки,
выбор канала доставки (email, push, SMS), выбор типа уведомлений (новости,
акции, системные оповещения), контроль срока действия подписки и её
текущего статуса.

## Основные сущности
- Подписчик (Subscriber) — пользователь, оформивший подписку
- Подписка (Subscription) — связь подписчика с типом уведомлений и каналом
- Тип уведомления (NotificationType) — категория рассылки (новости, акции,
  системные оповещения)
- Канал доставки (DeliveryChannel) — email, push, SMS

## Основные функции
- проверка статуса подписки (активна / истекла / приостановлена)
- расчёт количества дней до окончания срока действия подписки
- формирование текста уведомления для подписчика
- валидация email-адреса подписчика при оформлении подписки

## Возможности (ПР2)
- учёт нескольких подписчиков, типов уведомлений и подписок;
- добавление и поиск подписчиков и типов уведомлений;
- сортировка типов уведомлений;
- оформление подписки с запретом повторной активной подписки на тот
  же тип и канал;
- приостановка подписки без удаления записи из истории;
- просмотр статуса и формирование уведомления по конкретной подписке;
- хранение данных между запусками в JSON-файлах.

## Структура проекта
- `main.py` — точка запуска, меню приложения;
- `subscribers.py` — работа с подписчиками, `validate_email()` (ПР1);
- `notification_types.py` — работа с каталогом типов уведомлений;
- `subscriptions.py` — оформление и отмена подписок,
  `check_subscription_status()`, `days_until_renewal()`,
  `format_notification()` (все три — из ПР1, без изменений);
- `storage.py` — сохранение и загрузка данных в JSON;
- `utils.py` — безопасный ввод чисел, дат и канала доставки;
- `data/` — файлы данных;
- `tests/` — автоматизированные тесты.
