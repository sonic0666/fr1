## 3. Доработка индивидуального проекта

HTML больше не формируется в Python-коде: view-функции готовят контекст и вызывают `render()`.

- в `settings.py` указан каталог общих шаблонов `templates/` (`TEMPLATES['DIRS']`);
- создан базовый шаблон `templates/base.html` с блоками `title` и `content`, шапкой с логотипом, навигацией, подвалом и подключением Bootstrap, CSS и JavaScript;
- страницы наследуются от базового шаблона (`{% extends %}`);
- выделены включаемые шаблоны (`{% include %}`): навигация, карточка типа уведомлений, статус подписки;
- в шаблонах использованы теги `{% for %}…{% empty %}`, `{% if %}/{% elif %}/{% else %}`, `{% url %}`, `{% load static %}`, `{% static %}`;
- применены фильтры `|length`, `|default:"Без названия"`, `|date:"d.m.Y"`;
- ссылки строятся только через именованные маршруты с пространствами имён, жёстко заданных адресов нет;
- добавлены статические файлы: `style.css`, `main.js` (текущий год в подвале), `logo.png`;
- создан шаблон страницы 404 (`templates/404.html`), подключённый через `handler404`;
- в класс `Subscription` добавлено свойство `is_expired`; статус подписки отображается как «Активна», «Истекла» или «Приостановлена»;
- функция `page()` из ПР5 удалена;
- тесты веб-интерфейса расширены: проверяются использованные шаблоны, именованные URL, статические файлы, include статуса и фильтры; обновлён `README.md`.

## 4. Результат работы
