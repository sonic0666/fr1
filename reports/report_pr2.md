## 3. Индивидуальный проект

- **Название проекта:** Сервис управления подписками на уведомления
- **Репозиторий:** https://github.com/sonic0666/fr1 (коммит
  `ПР2: доработка проекта - модули, коллекции, JSON, исключения,
  тесты`)

**Реализованные функции:**

| Модуль | Функция | Назначение |
|---|---|---|
| `subscribers.py` | `validate_email()` | функция из ПР1, без изменений |
| `subscribers.py` | `add_subscriber()` | добавление подписчика в словарь, валидация email |
| `subscribers.py` | `find_subscriber()` | поиск по имени/email |
| `notification_types.py` | `add_notification_type()` | добавление типа уведомлений в каталог |
| `notification_types.py` | `find_notification_type()` | поиск по названию |
| `notification_types.py` | `sort_notification_types()` | сортировка по названию (lambda-ключ) |
| `subscriptions.py` | `check_subscription_status()` | функция из ПР1, без изменений |
| `subscriptions.py` | `days_until_renewal()` | функция из ПР1, без изменений |
| `subscriptions.py` | `format_notification()` | функция из ПР1, без изменений |
| `subscriptions.py` | `is_subscription_active()` | проверка активной подписки на тип+канал |
| `subscriptions.py` | `create_subscription()` | оформление подписки с проверками |
| `subscriptions.py` | `cancel_subscription()` | приостановка подписки |
| `storage.py` | `load_*()` / `save_*()` | чтение и запись JSON через `with`, обработка ошибок |
| `utils.py` | `input_int()`, `input_date()`, `input_channel()` | безопасный ввод с повтором при ошибке |

- **Структура модулей:** `main.py`, `subscribers.py`,
  `notification_types.py`, `subscriptions.py`, `storage.py`,
  `utils.py`, `data/` (JSON-файлы), `tests/` (3 файла тестов).
- **Формат хранения данных:** JSON-файлы
  `data/subscribers.json`, `data/notification_types.json`,
  `data/subscriptions.json` — списки словарей с полями сущностей
  (например, подписка: `id`, `subscriber_id`, `type_id`, `channel`,
  `end_date`, `is_active`).
- **Использованные конструкции:** словари и списки как основные
  коллекции; циклы для их обработки; исключения (`ValueError`,
  `KeyError`) при некорректном вводе и повторной подписке; работа с
  файлами через контекстный менеджер `with`; lambda-функция как ключ
  сортировки.

## 4. Результат работы

- код разделён на модули по смыслу (подписчики / типы уведомлений /
  подписки / хранение / ввод);
- данные переведены из отдельных переменных в словари и списки;
- реализованы функции добавления, поиска, сортировки и статистики;
- реализованы проверка доступности, оформление и отмена подписки;
- добавлена обработка исключений при вводе и работе с файлами;
- данные сохраняются в JSON и загружаются при следующем запуске;
- написано 18 автоматизированных тестов (pytest), все проходят;
- код проверен `flake8` без замечаний, добавлены аннотации типов;
- обновлён `README.md`, результат зафиксирован в Git.

объектную модель в ПР3.
