## 3. Доработка индивидуального проекта

Консольное приложение (ПР1–ПР3) дополнено веб-интерфейсом на Django.

- создано окружение и установлен Django 5.2 (`requirements.txt`: `Django==5.2.*`);
- командой `django-admin startproject` создан проект `notifyhub` (`manage.py`, `settings.py`, `urls.py`, `asgi.py`, `wsgi.py`);
- командой `startapp` созданы три приложения: `homepage` (главная), `notification_types` (типы уведомлений) и `subscriptions` (подписки); приложения подключены в `INSTALLED_APPS`;
- в `settings.py` указаны `ALLOWED_HOSTS`, `LANGUAGE_CODE = 'ru-RU'`, `TIME_ZONE = 'Europe/Moscow'`;
- настроена маршрутизация: корневой `urls.py` подключает `urls.py` приложений через `include()` с префиксами `/`, `/types/`, `/subscriptions/`;
- в каждом приложении задан `app_name`, маршрутам даны имена;
- реализованы view-функции главной страницы, списка и страницы типа уведомлений, списка и страницы подписки; страницы типов и подписок получают данные через `storage.py` и классы ПР3;
- адреса с параметрами используют конвертер `<int:...>`;
- для несуществующего типа или подписки возвращается код 404; для неизвестных адресов подключён `handler404`;
- в `models/subscriptions.py` добавлена функция поиска подписки по идентификатору (`find_subscription_by_id`);
- добавлены тесты веб-интерфейса (`tests/test_web.py`) и обновлён `README.md`.

| URL | Имя маршрута | Страница |
|---|---|---|
| `/` | `homepage:index` | главная |
| `/types/` | `notification_types:list` | список типов уведомлений |
| `/types/<int:type_id>/` | `notification_types:detail` | страница типа |
| `/subscriptions/` | `subscriptions:list` | список подписок |
| `/subscriptions/<int:subscription_id>/` | `subscriptions:detail` | страница подписки |

## 4. Результат работы

- проект запускается командой `python manage.py runserver`, команда `python manage.py check` ошибок не выявляет;
- все страницы открываются в браузере с кодом 200;
- запрос к несуществующему типу или подписке возвращает 404;
- консольная версия приложения (`main.py`) сохранена;
- результат зафиксирован в Git отдельными коммитами с меткой `PR5:`.
